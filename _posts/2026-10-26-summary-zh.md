## [C++26 标准在国家机构投票中被否决，堪称史无前例的挫折](https://www.linkedin.com/posts/robertseacord_balloting-has-completed-for-c26-unfortunately-activity-7519795140887035918-5PWL) ⭐️ 8.0/10

长期参与 ISO C++ 标准化工作的 Robert Seacord 报告称，C++26 的投票已经结束，各国家机构给出的结果是“否决（Disapproved）”，他表示这在 C++ 标准化史上是史无前例的。这意味着该草案未能获得顺利通过 ISO/IEC 投票阶段所需的批准。 C++ 是使用最广泛的系统编程语言之一，下一代标准在投票中受挫，将严重扰乱编译器厂商、库作者、工具供应商和教育工作者的计划节奏。这也引发了关于委员会共识机制与国家机构之间如何互动的疑问，并可能改变未来 C++ 标准的批准方式。 按照 ISO/IEC 规则，各国家成员机构是其所在国家的官方代表，在投票阶段既投票也提交技术意见；一旦结果为否定，委员会通常必须处理完这些意见并对草案重新投票。这份简短报告并未给出具体票数、所涉投票的确切类型（例如是委员会草案投票还是后续的批准投票），也没有列出投反对票的国家机构名单，因此否决的具体原因仍不明确。

rss · Lobsters · Oct 24, 18:00

**背景**: C++ 标准由 ISO/IEC JTC1/SC22/WG21 委员会（通常称为 C++ 标准委员会）制定，该委员会通过面对面会议把各项特性投票纳入工作草案。当草案被认为功能完备后，会被注册为委员会草案（Committee Draft）并送交各国标准机构投票；这些机构可以批准、否决或附意见批准，而它们的意见必须在文件进入最终出版前得到处理。C++26 是该语言的下一个修订版本，预计于 2026 年前后发布，也是反射（reflection）与契约（contracts）等重大新增特性的载体，这些特性已在过去几次会议上被投票纳入工作草案。

## [十年前的 Inception v3 卷积网络在皮肤癌诊断上胜过前沿大模型](https://lynchlab.net/llm-skin-cancer) ⭐️ 7.0/10

Lynch 实验室的一篇博客文章称，2015 年问世的图像分类卷积网络 Inception v3 先在日常照片上预训练，再用 ISIC Archive 中 68,011 张皮肤镜与临床图像在单块 H100 显卡上全层微调后，在皮肤病变诊断任务上胜过两个前沿大语言模型。测试用的 200 个病灶以及同一病灶或同一患者的其他所有图片，都在训练与验证阶段被剔除，因此模型此前从未见过它们。 这一结果让一个当下的争论更加尖锐：在什么场景下，小而专用的模型比通用大语言模型是更好的工程选择，尤其是在医学这类对准确率和成本都敏感的高风险领域。它同时引出对比较基准方式的质疑：大模型与专用分类器的这种对照实验，究竟测出了多少真正有意义的东西。 这个卷积网络刻意没有追求最先进水平——作者自己称 Inception v3 是过时的架构，选它部分是为了当作对照靶子；模型只在单块 GPU 上训练，阈值和模型选择都没有接触过留出患者的数据。Hacker News 上的批评者认为这属于“刷榜”（benchmaxxing），因为一个专门针对单一窄基准调优的模型，自然会打败从未针对皮肤镜图像优化过的通用大模型。

hackernews · sungam · Oct 25, 17:15 · [社区讨论](https://news.ycombinator.com/item?id=50233779)

**背景**: Inception v3 出自 Google 的 GoogLeNet/Inception 系列卷积神经网络，发布于 2015 年前后，它通过堆叠“Inception 模块”，并行使用多种卷积核尺寸，在保持图像分类精度的同时降低计算量。皮肤镜是一种可以放大皮肤病变的专用成像技术，公开的 ISIC Archive 已成为训练深度学习模型的标准图像来源。常见做法是迁移学习：先从一个在普通照片上预训练的网络出发，再用医学数据集微调其各层参数。相比之下，大语言模型是在广泛互联网数据上训练的通用文本与图像模型，而不是针对某一项诊断任务专门训练的。

## [OpenAI 与 Anthropic 大幅下调大模型 API 价格，降幅最高达 80%](https://minimaxir.com/2026/10/cheap-llms/) ⭐️ 7.0/10

根据 Max Woolf 在 minimaxir.com 发布的分析，OpenAI 与 Anthropic 在短短几个月内将其大语言模型 API 的价格下调了最高 80%。文章将这一轮降价归因于来自更廉价的中国模型与开放权重模型的竞争压力、推理成本的经济学规律，以及两家实验室可能存在的监管动机。 价格是决定大多数开发者和初创公司选择哪家模型的头号因素，因此 80% 的降幅可能迅速重塑市场份额，并挤压那些无法匹敌同等规模的小型供应商。这也标志着前沿大模型的访问正在变成一门商品化生意，利润空间更多取决于推理效率，而不仅仅是模型质量。 公开标价只能说明部分问题，因为实际单位成本取决于每 GPU 的 token 吞吐量、缓存、上下文长度和批量折扣等因素。评论者还提出了数据处理方面的隐忧，指出降价可能部分是由用户生成内容的再利用所补贴，而“零数据保留”（ZDR）承诺有时也出现过回撤。

hackernews · minimaxir · Oct 25, 21:11 · [社区讨论](https://news.ycombinator.com/item?id=50236102)

**背景**: 大模型推理经济学研究的是模型在生产环境中每次查询所产生的持续运营成本，这与一次性的训练资本开支不同。由于推理成本会随每个用户、每次 API 调用而线性增长，厂商只要提升硬件利用率、对模型做量化，或让单块 GPU 服务更多 token，就能大幅降价。与之竞争的开放权重模型——尤其是 DeepSeek 等中国实验室推出的低成本模型——为开发者提供了可信的替代方案，从而对现有厂商的定价形成下行压力。

## [俄勒冈警方为一名警员的记录开出 250 万美元、相当于 21 年工时的报价](https://theintercept.com/2026/10/01/oregon-police-misconduct-public-records-cost-fee/) ⭐️ 7.0/10

据 The Intercept 报道，美国俄勒冈州尤金市警察局告知一家当地新闻媒体，要完成其针对一名警员的公共记录申请，至少需要 44,816 个工作人员工时，费用约为 2,484,599.04 美元，按正常工作时间折算相当于约 21 年。该申请仅涉及一名警员的记录，因此这一报价相对于申请范围之窄显得极不寻常。 这一案例说明，高得离谱的收费可以变相等同于拒绝公开，使政府机构在不正式驳回申请的情况下就阻断新闻报道与公众监督。这对所有依赖公共记录法的人——记者、监督组织以及普通公民——都有切身影响，因为一份收费标准就足以让一部信息公开法形同虚设。 报道中提到的 44,816 小时折算下来约相当于一个人全职工作 21 年，而约 248 万美元的费用估值是该警察局所称检索和处理这些记录所需的成本。值得注意的是，警方并未直接拒绝该申请，而是用高得无法承担的报价让申请事实上无法推进。

hackernews · tdeck · Oct 25, 18:04 · [社区讨论](https://news.ycombinator.com/item?id=50234232)

**背景**: 公共记录法（在美国联邦层面即《信息自由法》，FOIA）允许公众申请获取政府机构持有的文件。多数此类法律允许机构对检索、审阅和涂黑处理文件所耗费的工时收取合理费用，这一条款的本意是弥补真实成本，而非吓退申请人。由于美国许多州的这类法律通常没有硬性期限，也不对估算费用设置上限，机构在定价和推进速度上拥有很大自由裁量权。

**社区讨论**: 评论者普遍认为 44,816 小时这一数字荒谬至极，并很快把讨论扩展到具体手法与跨国比较：有人描述某学区以每月寄送一小部分记录的方式达到同样的拖延效果；有人举出 2015 年美国国防部对一项 FOIA 申请估算需 1500 万小时、6.6 亿美元（超过 1700 年）的例子；还有人将美国做法与英国 30 天答复期限对比，并提醒德国正在讨论引入类似的阻却性收费。
